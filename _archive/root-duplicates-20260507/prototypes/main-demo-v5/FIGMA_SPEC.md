## 视觉总基调（关键纠正）

我现版 demo **整体太"重"**。Figma 实际更克制：

- 背景：纯白 / 极浅灰（不是我现在的 `#F7F7F8` paper），surface 几乎不可见
- 字色：**主文偏中灰**，不是纯黑；标题灰色（"HI, 今天想去哪儿呢？"是浅灰蓝色，**不是 ink 黑**）
- hairline 极轻
- 卡片几乎无阴影、靠极细边框分割
- **气泡：用户气泡是浅灰白底，不是我现在的暖橙；Assistant 文字裸文不带 bubble 框**
- CTA 蓝：`#174DFF` 类（保持）；价格红：`#FF3B30` 类用于关键价格点缀
- 圆角偏大（卡片 16-20px，按钮 pill）

## Frame 02 · 需求收敛

**关键模式**：assistant 多轮提问，每轮 2 个白底 pill 选项，用户点选后右侧出气泡，再进入下一轮。

| 序 | 内容 |
|---|---|
| 用户气泡（右） | "6月1号一早从东莞出发，怎么飞吉隆坡最便宜? 可以考虑中转。" |
| Assistant 文 | "为了更好的给你推荐行程方案，还需要回答几个问题，告诉我你的诉求：" |
| Q1 | "城市内交通你希望？" |
| Q1 选项 | `地铁或者公交` / `打车` |
| 用户回 | "打车" |
| Q2 | "如果需要中转，你希望尽可能" |
| Q2 选项 | `国内中转`（副文："无语言障碍，更方便沟通"）/ `都可以` |
| 用户回 | "国内中转" |
| Q3 | "你已经预订好酒店了吗?" |
| Q3 选项 | `我已经预订完成 (请告诉我具体的酒店名称)` / `帮我推荐` |
| 用户回 | "吉隆坡雪邦黄金海岸安凡尼度假酒店" |
| 状态 | "正在思考"（小灰字） |

我现版差距：完全没有这个多轮交互。我直接 1 user bubble + 1 assistant 收敛清单 → 立刻跳方案。

## 还需要你拍板的 3 件事

1. **行程数据用哪一版？**
   - A. 用 Figma 串联 Frame 08 的 4 段（轮渡 + 飞机 + 步行 + 打车）→ 跟产品流程内自洽
   - B. 用"综合交通行程_香港机场.png"那张数据表的 6 段（含打车出门 + 步行至打车点）→ 更详尽
   - C. 我合并：表层用 Frame 08 的 4 段，详情可展开成 6 段
   - **我推荐 A**，因为 Figma 是产品流，更新；6 段表是早期需求文档。

2. **乘机人示例数据用 Figma 真名？**
   - Figma 里写了 "李雷/张三/李四"，身份证 "310107 19990909 9999"。这是模拟数据，**保持原样安全**。我会照搬。

3. **机场段还要保留占位浮层吗？**
   - Figma 串联里**没有**香港机场段单独的占位层。整个机场内停留通过 Frame 08 行程① "广州 → 香港国际机场T1" 的下一段就直接跳到 Frame 08 行程② "香港机场T1 → 吉隆坡机场T1"，**中转默认在背后发生**，不暴露。
   - 你之前说"机场占位 + 后续接入真实机场展示"——这要求是**保留**还是**按 Figma 去掉**？
   - **我推荐"按 Figma 去掉占位层"**，因为它脱离 Figma 流；如果以后机场模块要接入，再加一个"行程 ② 详情"展开层（不是 sheet），跟 Figma Frame 04 选中态的"大画面详情"一致。

确认这 3 件后，我开始重写 main-demo。

## 重写主 demo 的执行顺序

按状态机和数据先重构，再换皮，再补支付密码键盘和地图：

1. **数据重写**：`src/data.js` 改为 Figma 串联的真实 plans / segments / passengers / order / 行前 / 推送
2. **状态机扩展**：增加 `requirement-flow`（多轮 Q&A）/ `itinerary-customize` / `order-passenger-pick` / `order-confirm` / `pay-pad` 等
3. **视觉降重**：tokens.css 调整白底 + 浅灰 + 蓝 CTA + 红价；用户气泡改浅灰
4. **首页重写**：3 张全文问句 + 4 件 composer
5. **需求收敛**：多轮 Q&A 模式
6. **方案推荐**：横向 3 卡轮播 + 4 步迷你时间轴 + 双 CTA
7. **行程定制**：行程图/线路图 tab + 编号 + 选中红框详情 + 建议 chip + 加载态
8. **全览图**：地图层（用静态 PNG 替代真实地图引擎）
9. **生单**：选乘机人 sheet → 订单 sheet → 飞猪密码键盘
10. **行前准备**：4 卡 + 我的行程横滑
11. **出行推送**：单卡
