0. 执行结论

本项目主线锁定为 Terminal 1。最终空间链路为：T1 Arrivals L5 到达，Immigration 入境检查，Baggage Reclaim 行李提取，Arrivals Hall A/B 到达大厅，上行至 T1 Departures L7，Re-check / Bag Drop 重新托运，Security 安检，Duty Free / Airside Spine 空侧商业主脊，Plaza Premium Lounge West Hall near Gate 60，West Gates 63-65 登机。

这条链路有较强官方依据。香港机场官方到达页面确认旅客在入境后领取行李并通过海关；官方 Special Needs Access 页面给出 T1、T1 Midfield、T1 Satellite 到港后进入 Level 5 的关系；官方 Departures 页面确认 Terminal 1 提供柜台值机和智能自助值机；官方 Pay-in Lounges 页面确认 Plaza Premium Lounge West Hall 位于 T1 Gate 60 附近、Departures Level L7。[S2][S3][S7][S11]

后续图像不能再做成单张孤立插画。每张图都必须包含三个锚点：A 锚点是上一张图的可见空间，B 锚点是当前主体，C 锚点是下一张图的可见空间。这个原则直接服务于你要的 flipbook 式连续浏览和首尾帧视频生成。

3.2 主线的空间方向

主线的视觉方向建议固定为“由东向西推进”。到达层从 T1 到港入口进入，经过 Immigration、Baggage Reclaim、Arrivals Hall 后做 L5 到 L7 的垂直抬升。到 L7 后，重新托运和 Security 构成第二段流程。Security 后进入空侧商业主脊，继续向西到 Gate 60 附近的 Plaza Premium West Hall，再向更西侧的 Gates 63-65 收束。

这套方向有利于视频模型处理。因为每一段画面都有明确方向，AI 不需要在不同帧之间重新猜测东、西、上下楼关系。

4. 六个缺口补证

4.1 Immigration 内部真实视角

可确认内容

官方到达流程确认 Immigration 位于 Baggage Reclaim 之前；Special Needs Access 到达页确认 T1 到达后进入 Level 5 处理，T1 Midfield 和 Satellite 到达也最终接入 Level 5。[S2][S3]

不足

官方资料没有足够完整的 Immigration 内部三维空间、排队栏、柜台数量和 e-channel 精确排布。

建图策略

  • 画成一段长条排队区，沿旅客方向设置多条通道。
  • 用“入境检查 Immigration”作为核心路线标注，带序号。
  • e-channel 与 manual counter 作为视觉元素出现，不写死数量。
  • 前端保留 Arrival Corridor，后端保留 Baggage Reclaim 入口。

Prompt 约束

“Immigration should be a structured passport-control hall with several parallel lanes, e-channel gates and manual counters. Keep the arrival corridor visible at the entrance and baggage reclaim visible at the exit. Do not invent exact official counter numbers.”

4.2 Baggage Reclaim Hall 高质量全景

可确认内容

官方资料明确显示 Baggage Belt 8 和 Baggage Belt 13 位于 Baggage Reclaim Hall, Arrivals Level L5。官方 Lost and Found 也位于 T1 Arrival Level L5，行李搬运服务从 T1 Arrivals Level 的 Baggage Reclaim Hall 到地面交通点。[S4][S5]

不足

公开资料支持“多转盘大厅”判断，但不提供完整可复刻的三维厅内全景。

建图策略

  • 画多个转盘，不只画单一转盘。
  • 保留中央柱体、电子屏、行李带、地面导向。
  • 前端与 Immigration 出口重叠，后端与 Arrivals Hall / Customs 出口重叠。
  • 不要出现密集文字，只保留“03 行李提取 Baggage Reclaim”。

4.3 Arrivals Hall 到上楼节点

可确认内容

官方设施资料出现 Arrivals Hall、Arrivals Hall A、Arrivals Hall B 与 Arrivals Level L5。用户上传的 APT Arrival Hall 图也展示了 Hong Kong Immigration、Baggage Reclaim Area、Customs、Exit A / Exit B、Arrival Hall、Hotel & Travel Agent Desks、Airport Express / Bus Terminal 等到达层关系。[S8][S15][S16]

不足

APT 图不是机场官方图，且图形偏旅行社接机用途。它能辅助理解 Exit A/B 和到达大厅公共区，但不能作为精确建筑平面。

建图策略

  • 画成从 Baggage Reclaim / Customs 出来后的公共大厅。
  • 保留 Exit A/B 或 Arrivals Hall A/B 的空间意象。
  • 需要出现通往 L7 的扶梯/电梯或 vertical transfer core。
  • 这张图承担 L5 到 L7 的转场前置，不能省略。

4.4 Re-check 柜台与 L7 关系

可确认内容

官方 Departure 页面确认 T1 可柜台值机，并有 100 多台智能自助值机。官方设施页面显示 Check-in Aisle A/D/K、After Departures North/South 等与 Departures Level L7 相关，行李打包服务位于 Check-in Aisle D/H, Departures Level L7。[S7][S8][S5]

不足

“Re-check 专用柜台”公开精确点位仍不足。若直接画一个固定柜台并标注为官方位置，风险高。

建图策略

  • 用“L7 Re-check Platform”表达，不把重托运点画成唯一柜台。
  • 主体为 Check-in Hall、Check-in Aisles、Re-check / Bag Drop 功能带。
  • 前端保留 Up from L5，后端保留 Security Entrance。
  • 核心路线序号 01-05 连续。

4.5 Security 后到 Duty Free Corridor

可确认内容

官方 Security 页面说明进入 Departures Immigration Hall 前需要准备登机牌和旅行证件。Transfer / Transit 页面同样说明转机旅客需要通过 security screening 后前往登机口。官方零售安排页面列出 T1 East Hall、Central Concourse 等商业和餐饮区域，支持 Security 后连接空侧商业带。[S9][S10][S14]

不足

公开资料不能精确还原 Security 出口到 Duty Free Corridor 的每一个转角和店铺顺序。

建图策略

  • 画成“安检出口 → 明亮商业走廊”的门槛转场。
  • 商业区不画具体品牌店，避免授权和位置误差。
  • 路径继续保持向西，露出后续 Airside Spine 与 Gate 60 方向。

4.6 Plaza Premium West Hall 多角度

可确认内容

HKIA 官方 Pay-in Lounges 明确列出 Plaza Premium Lounge West Hall 位于 Near Gate 60, Departures Level L7, Terminal 1，24 hours。Plaza Premium 官方页面确认 Gate 60 lounge 位于 Terminal 1，并描述有 natural light 与 tarmac view。[S11][S12]

不足

公开资料能支持位置和氛围，不能精确复刻内部座椅、墙面、吧台、动线。

建图策略

  • 外部入口图要让 lounge 成为 Airside Spine 旁的侧向进入点。
  • 内部图只画“高级、安静、自然光、停机坪视野”的通用感，不复制具体装修。
  • 出口图要回到 Airside Spine，并继续朝 Gates 63-65 推进。

5. 分支关系

5.1 Midfield Arrival

T1 Midfield Concourse 的到港分支应保留，但不进入主线编号。官方 Special Needs Access 页面说明，T1 Midfield Concourse 到达后在 Level 1 乘 APM 到 T1 East Hall，再前往 Level 5。[S3]

图中表达方式：紫色虚线，不带核心序号，标注“中场到达支线 Midfield Arrival via APM”。

5.2 Satellite Arrival

T1 Satellite Concourse 的到港接入需要保守处理。官方 Special Needs Access 页面说明，T1 Satellite Concourse 到达后在 Level 4 乘 airside passenger buses，到达 T1 后再前往 Level 5。[S3]

因此，Sky Bridge 可以作为物理结构背景，但到港分支不应强行画成所有旅客步行穿越 Sky Bridge。图中建议用浅紫色虚线表达“卫星到达接入 Satellite Arrival Connection”，同时弱化具体路径。

8. 单图 Prompt 生成约束

下一步不建议直接让模型自由发挥。每张图要用“母 Prompt + 局部 Prompt”的方式生成。

8.1 全局母 Prompt

Create a clean, modern, 45-degree isometric spatial map system for Hong Kong International Airport Terminal 1. Use a white background, light gray architectural volumes, pale blue glass, soft shadows, blue main route, and purple branch routes. The image must feel like a continuous visual canvas, not a standalone poster. Keep focus areas crisp, surrounding spaces softly faded, and route continuity visible. Use minimal bilingual labels. Main route labels must be Chinese + English, bordered, numbered, blue. Branch labels must be Chinese + English, unnumbered, borderless, purple or light gray. Maintain east-to-west orientation across all images. Each image must include an entry anchor, a focus area, and an exit anchor for smooth transition into adjacent images.

8.2 负面约束

Avoid dense explanatory text, inconsistent label styles, missing route numbers, random camera angle changes, isolated single-object compositions, over-top-down perspective, heavy old-style map clutter, excessive icons, exact copying of official photos, brand logos, and hallucinated detailed store locations.

9. 视频生成工作流

9.1 推荐路线

先生成静态组图，再用视频模型做图间过渡。不要直接让视频模型从文字生成整条路线，因为空间一致性会失控。

步骤工具方向用途
1图像生成生成 12 张连续空间画布。
2Seedance 2.0 或 Kling Start/End Frames用每一段的起始帧和结束帧生成 4 到 6 秒转场。
3Runway Gen-4补充环境一致性和局部镜头重试。
4Veo / Flow做镜头延展和更自然的 camera motion。
5剪辑软件拼接全部片段，统一速度和淡入淡出。

9.2 视频段落 Prompt 模板

Use image A as the start frame and image B as the end frame. Create a smooth spatial transition across one continuous 45-degree isometric airport map. Follow the blue passenger route from [start node] to [end node]. Keep the same east-to-west orientation, label style, route color, architectural style, and soft peripheral fade. Preserve all shared anchor spaces between the two frames. Do not rotate the camera, change the numbering system, invent new signage, or crop out the route continuation. The motion should feel like gliding across one infinite canvas.
